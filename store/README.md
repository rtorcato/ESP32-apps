# store

Web storefront and user dashboard for ESP32 apps. Name and design are pending
(Zoey's mockups); this is the plumbing only.

Stack: TanStack Start (React, file-based routing), Tailwind CSS v4, shadcn/ui
(`base-nova`, Base UI primitives).

```sh
pnpm install
pnpm dev          # http://localhost:3000, /dashboard
pnpm typecheck && pnpm lint && pnpm check && pnpm build
pnpm dlx shadcn@latest add <component>
```

Routes live in `src/routes/`; `src/routeTree.gen.ts` is generated by the router
plugin on dev/build — commit it, never edit it.
